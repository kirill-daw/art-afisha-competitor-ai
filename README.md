Домашнее задание **PEm08**. Приложение для анализа конкурентов сервиса **«Арт-Афиша»** — AI-ассистент, который собирает данные о конкурентах, анализирует их с помощью OpenAI и помогает находить точки роста.

## 📋 Краткое описание задачи

Проект автоматизирует конкурентный анализ в нише поиска культурных событий и покупки билетов. Пользователь может:

- проанализировать **текст** конкурента (описание сервиса, лендинг, реклама, тарифы для организаторов);
- проанализировать **изображение** (скриншот сайта или приложения, баннер, карточку события);
- запустить **автоматический сбор данных сайта** конкурента через Selenium и AI-анализ собранной страницы;
- просматривать **историю** последних запросов;
- работать как через **веб-интерфейс**, так и через **desktop-приложение на PyQt6**.

Результат анализа — структурированная оценка конкурента (сильные/слабые стороны, уникальные функции, оценки по шкалам 0–10, возможности для «Арт-Афиши» и итоговое резюме).

## 🎯 Ниша и цель анализа

- **Ниша:** сервисы поиска культурных событий, мероприятий и продажи/бронирования билетов (афиши, городские события, концерты, театр, выставки).
- **Цель анализа:** понять позиционирование и продуктовые возможности конкурентов, сравнить их по ключевым для «Арт-Афиши» направлениям и сформулировать **возможности для развития «Арт-Афиши»**.

## 🏷 Список анализируемых конкурентов

Список задаётся в `backend/config.py` (`competitor_urls` / `competitor_names`) и доступен через API `GET /competitors`:

| Ключ | Название | URL |
|------|----------|-----|
| `yandex_afisha` | Яндекс Афиша | https://afisha.yandex.ru |
| `afisha_ru` | Afisha.ru | https://www.afisha.ru |
| `kudago` | KudaGo | https://kudago.com |
| `timepad` | Timepad | https://timepad.ru |

Список можно расширить или изменить прямо в `backend/config.py`. В интерфейсе также можно указать **произвольный URL**.

## ✨ Основные возможности

- **Анализ текста** — структурированный разбор текстового описания конкурента.
- **Анализ изображений** — оценка интерфейса/баннера/карточки события по визуальным критериям.
- **Автоматический сбор данных сайтов через Selenium** — открытие страницы конкурента в headless-браузере, извлечение заголовков, описания, текста страницы и скриншота.
- **AI-анализ конкурентов** — анализ собранной страницы (скриншот + текст) через vision-модель OpenAI.
- **История результатов** — последние 10 запросов с типом, кратким описанием и временем.
- **Веб-интерфейс** — тёмная тема, вкладки «Анализ текста», «Анализ изображений», «Парсинг сайта», «История».
- **Desktop-приложение на PyQt6** — тот же функционал в отдельном нативном окне.

### 📝 Анализ текста

- Endpoint: `POST /analyze_text` (минимум 10 символов).
- Модель: `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`).
- Что можно анализировать: описание сервиса, текст с лендинга, рекламное объявление, описание тарифов для организаторов.

### 🖼️ Анализ изображений

- Endpoint: `POST /analyze_image`.
- Форматы: PNG, JPG/JPEG, GIF, WEBP (рекомендуется до 4 MB для быстрой обработки).
- Модель: `OPENAI_VISION_MODEL` (по умолчанию `gpt-4o-mini`).
- Что можно анализировать: скриншоты сайта/приложения, баннеры, карточки событий, оформление главной страницы.

### 🌐 Автоматический сбор данных сайтов через Selenium

- Endpoint: `POST /parse_demo` — принимает `url` **или** `competitor` (ключ/название из списка).
- Браузер запускается в headless-режиме; используется Selenium Manager для автоматического подбора WebDriver.
- Поддерживается **автоматический fallback Google Chrome → Microsoft Edge** — если Chrome не установлен, приложение пытается запустить Edge. Если недоступны оба браузера, возвращается понятная ошибка.
- Со страницы извлекаются `title`, `h1`, первый абзац, `meta description`, основной текст и **скриншот** страницы.
- ⚠️ **Приложение не обходит CAPTCHA и антибот-защиту.** Если сайт требует капчу, авторизацию или блокирует автоматический доступ, сбор данных для такого сайта завершится ошибкой/сообщением о блокировке.
- ⚠️ **Не гарантируется, что любой сайт всегда доступен для автоматического парсинга** — доступность зависит от самого сайта, его защиты, геолокации и изменений в вёрстке.

### 🤖 AI-анализ конкурентов

- Если удалось получить скриншот — анализ идёт через vision-модель (`analyze_website_screenshot`).
- Если скриншот недоступен — используется текстовый анализ собранного контента (`analyze_parsed_content`).
- Результат — структура `CompetitorAnalysis` (см. раздел «Поля конкурентного анализа»).

### 📋 История результатов

- Endpoints: `GET /history`, `DELETE /history`.
- Хранит последние **10** запросов в файле `history.json`.
- Для каждого запроса сохраняются: тип (`text` / `image` / `parse`), краткое описание запроса, краткое описание ответа и время.

### 🌐 Веб-интерфейс

- Отдаётся backend'ом по адресу `http://localhost:8000/`.
- Вкладки: анализ текста, анализ изображений, сбор и анализ сайта (с выбором конкурента или своим URL), история.
- Ответы и оценки отображаются в виде блоков; отсутствующие значения показываются как «н/д».

### 🖥️ Desktop-приложение на PyQt6

- Папка `desktop/`, запуск `python main.py`.
- Повторяет функциональность веб-интерфейса: анализ текста, анализ изображений (drag & drop), парсинг сайта с выбором конкурента, история.
- Общается с backend по HTTP (`http://localhost:8000`), не содержит секретов и API-ключей.

## 🛠️ Используемые технологии

- **Backend:** FastAPI, Uvicorn, Python 3.9+
- **AI:** OpenAI API (текст и vision), официальный `openai` SDK
- **Автоматический сбор:** Selenium (headless Chrome / Edge, Selenium Manager)
- **Парсинг HTML:** BeautifulSoup4, lxml
- **Валидация и конфиг:** Pydantic, pydantic-settings, python-dotenv
- **Frontend:** HTML5, CSS3, Vanilla JS
- **Desktop:** PyQt6
- **Сборка .exe:** PyInstaller

## 🚀 Установка

### 1. Клонирование и виртуальное окружение

```bash
git clone <URL-вашего-репозитория>
cd art_afisha_competitor_ai_app

python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate
```

### 2. Зависимости backend

```bash
pip install -r requirements.txt
```

### 3. Зависимости desktop-приложения (опционально)

```bash
pip install -r desktop/requirements.txt
```

### 4. Настройка `.env` через `OPENAI_API_KEY`

Создайте файл `.env` в корне проекта (шаблон — `env.example.txt`):

```env
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o-mini
OPENAI_VISION_MODEL=gpt-4o-mini
```

- `.env` добавлен в `.gitignore` — **не публикуйте реальные ключи**.
- Ключ можно получить в личном кабинете OpenAI: https://platform.openai.com/api-keys
- При отсутствии `OPENAI_API_KEY` приложение завершится с понятной ошибкой при старте.

## ▶️ Запуск

### Backend (и веб-интерфейс)

```bash
python run.py
```

Либо напрямую через Uvicorn:

```bash
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

- Веб-интерфейс: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

### Desktop-приложение (PyQt6)

Сначала запустите backend, затем в отдельном терминале:

```bash
cd desktop
python main.py
```

Приложение подключится к backend по адресу `http://localhost:8000`.

## 📦 Сборка .exe (desktop)

Сборка выполняется из папки `desktop/` (требуется установленный PyInstaller):

```bash
cd desktop
pip install -r requirements.txt
python build.py
```

Готовый файл появится в `desktop/dist/CompetitorMonitor.exe`.

Очистка артефактов сборки:

```bash
python build.py clean
```

> Backend собирается и запускается отдельно — `.exe` desktop-клиента обращается к уже запущенному backend.

## 🧪 Поля конкурентного анализа

### Текстовый анализ / AI-анализ сайта — `CompetitorAnalysis`

| Поле | Тип | Описание |
|------|-----|----------|
| `strengths` | `string[]` | Сильные стороны конкурента |
| `weaknesses` | `string[]` | Слабые стороны конкурента |
| `unique_features` | `string[]` | Уникальные функции и предложения |
| `event_discovery_score` | `int \| null` | Удобство поиска и обнаружения событий (0–10) |
| `personalization_score` | `int \| null` | Персонализация и рекомендации (0–10) |
| `regional_coverage_score` | `int \| null` | Охват городов и регионов (0–10) |
| `ticketing_score` | `int \| null` | Покупка и бронирование билетов (0–10) |
| `organizer_tools_score` | `int \| null` | Возможности для организаторов (0–10) |
| `content_quality_score` | `int \| null` | Качество описаний, подборок и редконтента (0–10) |
| `opportunities_for_art_afisha` | `string[]` | Возможности для развития «Арт-Афиши» |
| `summary` | `string` | Краткое итоговое резюме |

Оценки могут быть `null` (нет достаточных данных во входных данных) — в интерфейсе они отображаются как **«н/д»**.

## ⚠️ Ограничения

- **CAPTCHA и антибот-защита не обходятся.** Сайты с капчей, авторизацией или активной защитой от ботов могут быть недоступны для автоматического сбора данных.
- **Не гарантируется, что все сайты всегда доступны для автоматического парсинга** — доступность зависит от самого сайта, его политики, защиты, геолокации и изменений вёрстки.
- Selenium требует установленного браузера (Chrome или Edge). При отсутствии обоих сбор данных через Selenium невозможен.
- Для работы AI-анализа и сбора данных требуется интернет-соединение и валидный `OPENAI_API_KEY`.

## 🔐 Безопасность

- Не храните API-ключи в коде — используйте `.env`.
- `.env`, `.venv`, `__pycache__`, `*.pyc` и другие локальные/секретные файлы добавлены в `.gitignore`.
- В `.env` в репозиторий попадает только шаблон `env.example.txt` без реальных ключей.
